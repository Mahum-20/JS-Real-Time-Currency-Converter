Real-Time Currency Converter

**Description**

The Real-Time Currency Converter is a web-based application developed using HTML, CSS, and JavaScript. This tool allows users to convert currencies in real time by fetching up-to-date exchange rates from the Currency API. The exchange rates are updated daily, ensuring accurate conversions.

**Features**

Fetches real-time currency exchange rates.

Converts any supported currency to another.

Simple, intuitive, and user-friendly interface.

Automatically updates rates daily for accuracy.

**Technologies Used**

HTML: For structuring the web page.

CSS: For styling the interface.

JavaScript: For dynamic functionality and fetching API data.

**Installation and Setup**

Clone this repository to your local machine:

git clone https://github.com/your-username/real-time-currency-converter.git

Navigate to the project directory:

cd real-time-currency-converter

Open the index.html file in your browser to run the application.

**How It Works**

The application fetches the latest exchange rates from the Currency API on page load.

Users can select the source currency, target currency, and input the amount they wish to convert.

The conversion is calculated using the real-time exchange rate.

**API Details**

The app uses the free Currency API, which provides:

Exchange rates updated daily.

A comprehensive list of global currencies.

**Example Usage**

Select a source currency (e.g., USD).

Select a target currency (e.g., EUR).

Enter the amount to convert (e.g., 100).

View the converted value displayed in the result area.
